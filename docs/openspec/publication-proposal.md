## Why

Afterlight is a verified local application, but visitors need a public repository, a useful visual README, a downloadable release and a working online entry point. Publication must retain its complete study workflow and keep local provider credentials outside the deployed site.

## What Changes

- Publish the maintained application, tests, original artwork and selected rationale as `starright00631-dev/afterlight`.
- Add the unmodified PolyForm Noncommercial 1.0.0 license, required notice and third-party license records.
- Provide an explicit browser deployment with local records and PDF reading; retain provider assistance in the localhost application.
- Add reproducible verification and GitHub Pages deployment workflows, and publish a versioned 3.2 release with verified archive hashes.
- Replace the local delivery README with formal installation, capability, workflow and visual documentation.

## Capabilities

### New Capabilities

- `public-distribution`: Licensed source and release distribution with an independently usable browser deployment.

### Modified Capabilities

None. No main specifications currently exist; existing study/model behavior remains covered by the completed change records.

## Impact

Browser service adapters, PDF intake, build scripts, package metadata, public documentation and GitHub workflows change. Model calculations, v3 storage and the loopback-only Node service remain compatible. No hosted provider credentials or public Node service are introduced.
