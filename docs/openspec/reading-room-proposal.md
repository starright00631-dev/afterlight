## Why

Afterlight 3.0.0 already supports durable lighting studies, matched alternatives and evidence exports, but its procedural canvas and dense controls do not yet convey the detailed reading room shown in the approved day/night concepts. A focused 3.1.0 refinement can make that place tangible while making Arrange → Predict → Compare → Choose an actionable path through the existing scientific workflow.

## What Changes

- Add original illustrated room assets and a restrained warm wood, brass, ink and parchment visual system, with readable controls over the artwork in both appearances.
- Keep lamps, screens, measurement points, paths and illuminance model-driven and movable; use generated art for room atmosphere and surface material rather than a flattened UI screenshot.
- Present a deliberate stage, compact study brief, live reading strip and four real workflow actions, with progressive access to detailed controls and retained workspace destinations.
- Add a calculated B − A difference-field view for two distinct immutable saved alternatives only when their surface and measurement setup match. Preserve numeric per-point comparison and explain both sign and scale.
- Preserve unfinished predictions/conclusions, saved arrangements, target snapshots, study ownership, source links, exports and separate real observations across appearance changes and navigation.
- Verify the interactive redesign at desktop, compact and mobile sizes, with keyboard controls, reduced motion and empty fresh records, then package one auditable 3.1.0 release.

## Capabilities

### New Capabilities

- `immersive-reading-room`: An illustrated yet model-driven studio with an actionable workflow, honest matched difference visualization and responsive accessible presentation.

### Modified Capabilities

None. `openspec list --specs` returns no main specs. Implemented change `unify-afterlight-studio` supplies the 3.0 baseline; this change adds a focused presentation and comparison-view contract without redefining its storage or optical model.

## Impact

Affects `afterlight/studio-renderer.js`, `studio-ui.js`, `studio.css`, the shared shell styles, original packaged illustration assets, a pure difference sampler if needed, targeted tests, release documentation and packaging. The existing ideal point-source model, persistence version, provider services and Windows launcher remain the compatibility baseline. No runtime generated code, external renderer framework, fake history or empirical lighting claims are introduced. The 3.0.0 release archive is retained as a rollback artifact before the authoritative archive is replaced.
